# C6 试用后的集中修订

本批依据完整关闭的 C6 试用，统一处理五项发现。试用期间没有修改 Studio；修订经最终自检后再进入新的冻结试用。自动回归、操作员试玩和隔离模拟接受分别记录，均不代替真人验收。长期完整验收范围保持原文有效。

| 发现 | 修订 | 可核对结果 |
| --- | --- | --- |
| 定义草稿未传到实例大小和运动示意 | 增加明确的 `sizeFieldId`；实例按 `definitionId` 读取定义绑定和运动字段 | 定义宽度、速度、时长草稿与实例大小、速度、推导位移一致 |
| 位置属性与场景示意不同步 | 增加明确的 `positionFieldId`，场景、详情和位置控件使用同一属性草稿 | 属性输入、拖动、微调和位置控件保持一致；绑定位置不重复生成结构移动 |
| 390 宽的技术验证长文本撑页 | 验证容器允许收缩，技术列表按需换行 | 长 Git 身份和 JSON 在自己的验证区域内可读；场景仍独立滚动 |
| 预览轮询清空未保存截图 | 同一项目、选择代次、作业、冻结表单及修订、候选和 Git 保留原生表单 | 原文件、条件、焦点及重试请求身份保留；候选或编辑状态变化时清空隔离 |
| 候选对照只剩澄清代号 | 公开冻结输入保留按原顺序排列的用户原文、回答及策划问题和选项 | 回看显示原中文问题与对应选项；不把策划摘要当用户要求 |

`positionFieldId`、`sizeFieldId` 引用同一对象上的 `vector2` 字段，大小为正数。实例自身绑定或显式大小覆盖优先，否则继承定义的大小绑定。运动实例自身未声明速度时继承定义的运动速度，明确声明的 0 仍有效；继承阶段的字段引用仍属于定义。公开 schema、后端验证、策划契约和制作规格同步描述这些规则。

没有绑定的旧文档保留静态或未知显示，不从中文字段名、说明或关系名称猜绑定，也不改写旧候选。明确绑定但无效或有歧义的草稿显示未确认；来源几何与当前草稿分开。浏览器示意不证明引擎运行；每次制作仍执行独立工程准备和验证，且不授予托管模型额外执行权限。

截图提交期间固定原文件和条件。读取结果可以刷新而不重建表单，保存前的迟到读取不能覆盖保存后的结果。跨项目、候选、Git、冻结修订或历史状态不复用表单。网络失败保留原文件与条件，使用原请求身份重试。
