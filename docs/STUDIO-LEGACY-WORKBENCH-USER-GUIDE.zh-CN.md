# Studio 对象工作台操作指南

日期：2026-10-15（Asia/Shanghai）。本文说明当前 Studio 中已经提供的对象工作台入口及其数据边界，供日常浏览、提出修改和跟踪结果时参考。

本指南描述当前页面操作，不代表完整复刻目标已经完成或通过用户验收。对象、场景、可编辑字段、来源和预览取决于当前项目公开快照及其工作台元数据；缺少映射时，页面会提示“未提供”或“未映射”，不会据此推测事实。完整目标与逐项进展见[旧版工作台复刻目标](STUDIO-LEGACY-WORKBENCH-REPLICATION-GOALS.zh-CN.md)和[定向评估记录](STUDIO-LEGACY-REPLICATION-EVALUATION.zh-CN.md)。

## 从对象目录开始

进入可迭代的项目后，在“当前工作台”打开“项目对象”。左侧目录支持按名称或 ID 片段筛选；要精确定位时，输入完整 ID 并按 Enter。分类下拉框可过滤共享定义、场景、实例、入口、生成规则、行为、状态、资源、场景过渡、预设等已映射角色。点选对象后，面包屑、画布、右侧详情和意见输入都跟随同一目标。可从关系或使用处跳到关联对象，再用面包屑回到项目或场景。

“Design · 设计”“Narrative · 叙事”“Art · 表现”是同一目标的不同观察面。切换观察面不会改意见归属；没有叙事或表现来源时，页面会明确显示未提供。右侧详情可查看对象 ID、作用范围、定义、所属场景、锁定状态、位置、关系和使用处；“来源、覆盖与诊断”展开后可检查来源路径、覆盖情况，并按当前发布版本读取静态来源。需要时再打开源码差异，避免把对象文档中的描述误当成源码事实。

场景画布可切换场景，并单独开关网格与“入口 / 出口标记”。有公开世界边界和位置数据时，画布按这些数据展示场景编排；缺少边界或位置时，会退回语义关联列表，不能把卡片位置当成真实游戏布局。图片或动画剪辑预览只读取实际绑定的发布来源；有动画剪辑时显示其真实首帧描述。浏览器里的阶段轮播是理解用示意，不代表 Godot 引擎中的播放结果。

窄屏可用工作区上方“导航”“预览”“详情与意见”切换当前面板。

## 提出修改与记录反馈

在右侧“本目标意见”的“希望怎样修改”写自然语言期望。输入会按当前稳定对象 ID 自动保存到此浏览器中的本地草稿；切换目标后，每个目标的意见仍分别保留。左侧“项目级 · 项目意见与概览”用于整体要求；目录中的系统对象仍有各自职责和意见。只读字段、尚未映射的行为或资源也可以先写意见，交由 Agent 流程处理。数值控件并列显示来源中的当前值、本轮期望及尚未制作状态；改回原值后不再计入差异。

需要另记一条意见时，展开“添加另一条分类意见”，选择一般、问题、视觉或行为，再点“加入修改清单”。未加入的文字和分类也按输入时的目标保存；切目标不会改绑，提交前会提示先处理待加入文字。已加入意见与主要意见都在统一申报中编辑、移除和定位。没有原目标记录的旧反馈会保留为待关联文字，需要明确关联后才能提交。

局部要求请先选中具体实例，再写明“只改当前实例、其他同类保持不变”等范围和保留条件。共享定义会标明所有同类及已知使用处；实例没有独立控件时，局部意图仍交给 Agent 分析并进入方案审阅，不会因选中实例就证明工程已有独立配置。固定约束同时限制工作台中的移动和删除；游戏运行时的角色运动另由游戏逻辑决定。

创建结构意图时，所有操作先成为本地草稿中的待申报提案，不会立即改写工程文件：

- **提议新场景**：填写名称，可选“空白场景”或“最小结构模板”，也可填写出入口或连接说明。世界宽度与高度必须一起留空，或一起填为正数。最小模板的地板和玩家入口标记仅表达本地意图，不会创建 Godot 节点。
- **提议新实例**：选择一个已映射的共享定义，以及具有公开世界边界的场景，再选自由、可微调或固定约束。提交表单后进入放置预览；在所属场景画布点击位置完成本地放置，按 Escape 或点“取消放置”则取消这次放置操作。无世界边界时不能校验坐标，也不能把实例自身的 bounds 当作场景边界。
- **调整实例位置**：free 实例可以在画布拖动，也可以用坐标控件；nudge 实例用方向按钮按声明步长微调；fixed 实例不可移动。坐标按场景世界边界、实例大小和锚点共同校验。删除实例同样是待申报操作，并受其锁定约束限制。
- **网格对齐预览**：在“手动网格对齐预览”中明确勾选实例并设置间距。预览只运行本地对齐算法；检查差异后点“应用到本地草稿”，才会将可用移动作为一组成组可撤销的提案。锁定、越界、无需移动或预览已过期的项目会跳过或拒绝应用。
- **操作示例**：“整理装饰布局”仅对明确映射为装饰且允许移动的实例做局部网格对齐，不运行寻路，也不保证通路。时长示例按实际映射命名，Casino 显示骰子预警调整；预览列出精确对象、字段和前后值，历史示例来源可展开查看。缺少对应映射时不能应用。两者都只生成本地草稿差异，一般自然语言仍经统一申报交给真实 Agent。
- **场景过渡**：每条有向过渡单独填写来源、目标场景、目标入口、通行条件和模式（未设置、无过渡、共享预设）。编辑当前已映射过渡时，表单关联该方向的原过渡；反向过渡需另行选择和处理。入口必须属于所选目标场景，且共享预设只允许选择被映射为过渡预设的对象。当前项目没有映射的连接不会被工作台补造。

可在“待申报结构提案”检查或移除操作。草稿场景、草稿实例的 ID 是工作台生成的局部稳定 ID；只有申报后经 Agent 处理，才可能成为工程中的实际对象。

## 检查并提交统一申报

点“预览统一申报”后，工作台把自然语言意见、支持的字段差异、已添加反馈和结构提案汇总到同一份预览。提交前可定位原目标、编辑或移除意见、移除字段差异。意见编辑中的变更会保留在本地；“完成编辑并更新预览”后才可发送，只打开编辑框而未改文字不阻止提交。同目标参数与原文可以选择“两项都执行”；明确矛盾可指定本轮处理方式或先澄清。相关参数、原文、范围或基线变化后，旧决定保留供核对并标记失效，不会继续作为指令发送。

没有实际变化或有效意见时不能创建空任务。点“取消预览”只关闭预览；点“交给当前 Agent 流程”提交当次已审阅内容，等待期间新写的内容属于下一轮草稿。方案就绪后，制作前主卡按“你的要求、AI准备怎样做、影响谁、保持什么、怎样验证”供核对；关联检查对象不等于都会修改。澄清回答和READY补充按方案修订自动保存；新修订不会套用旧答案，旧文字可展开查看。

交给 Agent 只表示本轮已发送到现有流程，不代表工程已修改。结果卡逐项显示原文、处理决定、期望与记录值、源码变化、技术验证及未完成原因；没有运行情境证据的项目保留“待试玩”。可用“回到原对象继续调整”或“查看候选与试玩入口”接着操作。文档值匹配不等同运行效果通过；整版技术通过也不会解决所有遗留意见。候选的“接受为当前版本”将其设为本机已接受版本；“继续修改此候选”沿用现有拒绝与返修流程。上述决定与逐项体验判断分别记录。

结果不合意时，可回到原对象继续补充意见或字段调整，再通过同一工作台发起下一轮。无需把结果卡上的处理决定或 Agent 摘要当成用户原文；两者在结果中分别呈现。

## 草稿、撤销与恢复

工作台持续自动保存编辑中的草稿，并按项目、已接受版本和返修候选隔离。右侧状态提示可查看本地保存状态。“创建 / 更新恢复点”另存一个显式恢复点，显示时间与作用范围；更新前会询问，并保留首次被替换的恢复点备份。例如保存 A 后确认更新为 B，再更新为 C，当前恢复点为 C、首次备份仍为 A；取消更新则保持原恢复点。“恢复到恢复点”在确认后替换当前工作草稿，这个替换可撤销。“重置当前草稿”同样可撤销。

“导出草稿”准备 JSON 下载，分别包含当前工作草稿、可读取的已保存检查点和首次覆盖备份，各自保留原文与意见身份；它不会提交申报或启动 Agent。文件是否落盘以浏览器下载结果为准。遇到损坏或不兼容存档时，工作台保留原始字符串并暂停写入，草稿状态区提供“下载原始存档”和“查看/复制原始存档”。查看窗口中的完整恢复 JSON 只读，不会自动覆盖或提交；点击复制会立即全选并提示手动复制，剪贴板及时成功时再显示“已复制”。浏览器拒绝或等待超过 1.5 秒时，可按 Ctrl+C 或 ⌘C 复制选中的全文。Ctrl/Cmd+Z 撤销，Ctrl/Cmd+Y 或 Ctrl/Cmd+Shift+Z 重做；当焦点在输入控件中时，快捷键留给文本编辑器。

同一浏览器的另一个标签页写入不同内容时，工作台会提示跨标签草稿冲突；比较本页与另一标签的内容后，再选择保留哪份作为当前版本。冲突处理中保留的另一份可从草稿状态区恢复。它不是自动合并或实时同步；关闭提示也不等同于解决冲突。不同设备之间不共享此浏览器本地草稿。存储失败时先按页面提示复制或导出内容，再继续编辑。

## 解释当前 Casino 数据时的边界

当前 Casino 工程中由程序绘制的内容没有对应 PNG 美术素材；没有真实绑定图片的对象应查看语义预览和来源说明，不能把占位图或其他项目资源说成 Casino 原图。运行时临时生成的对象也不因此成为持久的场景实例或永久摆放位置。工作台的中立示例或夹具只用于理解通用操作，不代表当前 Casino 已有这些场景、过渡、入口或素材。

本文是操作说明，不是完整目标的验收结论。当前能力、证据范围和待补路径以[定向评估记录](STUDIO-LEGACY-REPLICATION-EVALUATION.zh-CN.md)为准；更完整的用户交互与流程参考见[交互序列说明](STUDIO-USER-INTERACTION-SEQUENCES.zh-CN.md)。
